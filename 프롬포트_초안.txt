너는 웹 앱 개발자야. 아래 기획대로 "회시모(CIMO)"라는 팀 일정 조율 웹앱을 만들어줘.
휴대폰에서 바로 써볼 수 있는 완성된 웹 페이지로 만들고, 팀원들이 같은 방의 데이터를 함께 볼 수 있게 공유 저장 기능을 써줘.
첨부한 화면 시안 이미지가 있다면 레이아웃과 분위기를 따라줘.

[서비스 개요]
- 서비스명: 회시모(CIMO) — 회(계사들의) 시(간) 모(으기), 확장 시 "회의 시간 모으기"
- 슬로건: 단톡방 핑퐁은 그만, 링크 하나로 끝내는 5초 팀 일정 조율
- 문제: 단톡방에서 회의 시간을 정할 때 생기는 대기(답이 늦음), 누락(읽고 넘어감), 중복(누군가 다시 취합)
- 해결: 링크 하나를 공유하면 팀원들이 각자 가능한 시간을 표에 칠하고, 겹치는 시간이 색으로 자동 표시되고, 최적 시간을 1·2·3순위로 추천
- 회원가입·로그인 없음. 이름과 직급만 적으면 시작

[회의 만들기]
- 모임 이름(필수)
  - 이름을 적으면 바로 아래에 "장소, 안건 등 세부내용을 입력하시겠습니까?" 안내와 [입력] [괜찮아요] 버튼 표시
  - [입력]을 누를 때만 세부내용 입력칸이 열림, [괜찮아요]를 누르면 접히고 "+ 세부내용 추가" 링크만 남음
- 후보 날짜(필수): 달력에서 여러 날짜를 눌러 선택(지난 날짜는 선택 불가), 선택한 날짜 수 표시
- 시간대: 시작·종료 시각을 1시간 단위로 선택, 기본 00:00~24:00
- 시간 단위("표에서 한 칸의 길이"): 15분 / 30분 / 45분 / 1시간 버튼, 기본 30분
- 소요 시간("회의가 걸리는 시간"): 1시간 / 2시간 / 3시간 / 직접 입력 버튼, 기본 1시간
  - 직접 입력을 누르면 [ ]시간 [ ]분 숫자 칸이 열림(최대 12시간 59분)
  - 소요 시간은 시간 단위의 배수일 필요 없음
- 투표 마감(선택): 날짜·시간 입력 + [마감 없음] 버튼
  - 기본값은 일주일 뒤 00시, 첫 후보 날짜가 그보다 빠르면 그 날짜 00시로 자동 조정
  - 방장이 직접 바꾸면 자동 조정하지 않음
- 모임 담당자: 이름 + 직급(필수)
- 참여 총 인원(필수, 담당자 포함): −/+ 버튼, 기본 4명
- 꼭 참석해야 하는 사람(선택)
  - 담당자는 자동으로 필참자이고, "★ 이름 담당자" 칩으로 고정 표시(삭제 불가)
  - 이름을 입력해 추가(칩을 누르면 삭제), 또는 직급으로 지정(여러 개 선택 가능)
  - 직급으로 지정하면 그 직급으로 입력한 사람 모두가 필참자
- 방장 비밀번호(필수, 4자 이상): 일정 확정·취소와 방 설정 수정에 사용
- 직급 범위(앱 전체 공통): 파트너, 디렉터, 매니저, 시니어, 스태프
- 검증 문구 예: 소요 시간이 시간대보다 길면 "소요 시간이 시간대보다 길어요.", 필참자가 총 인원보다 많으면 안내

[우선순위 논리]
평가 단위:
- 각 후보 날짜에서 시간 단위 칸의 시작점마다 "시작 시각 ~ 시작 시각+소요 시간" 구간을 후보로 봄
- 그 구간에 걸치는 칸을 모두 칠한 사람만 참여 가능으로 계산
  (예: 1시간 단위 표에서 1시간 40분 회의면 10시·11시 칸을 모두 칠해야 10:00–11:40 가능)
- TOP 3는 서로 시간이 겹치지 않는 구간으로 선택
순위:
- 1순위: 필참자 전원 참여 + 나머지 인원 전원 참여 (전원 = 방 생성 시 입력한 총 인원)
- 2순위: 필참자 전원 참여 + 나머지 인원 일부 참여
- 3순위: 필참자 일부 참여
세부 규칙:
- 같은 순위 안에서는 참여 가능 인원이 많은 구간이 위, 같으면 빠른 날짜·시간 순
- 필참자가 없으면 참여 가능 인원이 많은 순서로 추천
- 필참자가 1명뿐이면 3순위는 해당 없음
- 필참자 수 = 담당자 + 이름으로 지정한 사람(아직 안 들어왔어도 포함) + 지정 직급으로 입력한 사람
