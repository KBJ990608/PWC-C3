# CIMO (회시모)

단톡방 핑퐁은 그만, 링크 하나로 끝내는 팀 회의 일정 조율 웹앱

삼일 PwC 2026 Discover 신규입사자 연수 **C-3조 사전과제**

🔗 **배포 주소: [https://cimo-pwc.vercel.app](https://cimo-pwc.vercel.app)**

## 어떤 서비스인가요

로그인 없이 회의방을 만들고 링크나 6자리 코드를 공유하면, 참여자들이 각자 가능한 시간을 칠해요.
모인 시간은 **히트맵**으로 한눈에 보이고, **필참자 조건**을 반영한 **추천 TOP3**를 보고 방장이 **일정을 확정**해요.
방 데이터는 Supabase에 저장돼서 다른 기기·브라우저에서도 같은 방을 보고, 누가 시간을 저장하면 새로고침 없이 바로 반영돼요.

## 주요 기능

- **회의방 만들기**: 모임 이름·세부내용, 후보 날짜(달력에서 여러 날), 시간대, 시간 단위(15·30·60분), 소요 시간, 투표 마감, 총 인원, 필참자, 방장 비밀번호
- **6자리 방 코드 · 초대 링크**: `#room=코드` 링크로 바로 입장, 단톡방용 초대 문구·재촉 문구 복사
- **내 정보(프로필)**: 이름·부서(CM·TMT·IME)·직급(주니어·시니어·매니저·디렉터)을 한 번 등록하면 방마다 자동 입력, 방을 만든 사람은 자동으로 담당자·필참자
- **가능한 시간 선택**: 표의 칸을 눌러 표시(PC 드래그, 모바일 드래그 선택 옵션), 이미 확정된 내 다른 CIMO 회의는 회색 빗금으로 표시
- **히트맵**: 칸마다 가능 인원 수와 진하기, 전원 가능한 칸은 황금색, 칸을 누르면 가능·불가능·미입력자 명단
- **필참자 설정**: 이름으로 지정(정확히 그 사람) 또는 직급으로 지정(부서와 무관하게 그 직급 중 1명)
- **추천 TOP3**: 아래 기준으로 자동 추천, 카드를 누르면 히트맵에서 해당 시간 강조
- **참여 현황**: 완료 인원/총 인원 진행바, 완료자·미입력 필참자 목록
- **총 인원 제한**: 정원이 찬 방에는 새 참여자가 저장할 수 없음(기존 참여자는 계속 수정 가능)
- **일정 확정**: 방장 비밀번호로 TOP3 중 선택하거나 직접 시간 선택, 확정 시 컨페티와 확정 배너, 확정 취소 가능
- **방 설정 수정**: 이름·세부내용·총 인원·마감·필참자·비밀번호 변경
- **CIMO 캘린더**: 내 모임을 달력으로 보기(확정 / 조율 중 / 지난 모임)
- **내 모임 목록**: 다음 모임, 진행 중인 조율, 지난 모임, 즐겨찾기, 목록에서 나가기
- **실시간 공유**: Supabase Database + Realtime
- **다크/라이트 테마**, 이용 방법을 보여주는 **예시 방**(코드로 참여하기 → 이용 방법 보기)

## 추천 TOP3 기준

후보 시간(회의 소요 시간 길이의 연속된 구간)을 먼저 3개 등급으로 나눈 뒤 정렬해요.

| 순위 | 조건 |
|---|---|
| 1순위 | 필참자 전원 가능 **+** 전체 인원 전원 가능 |
| 2순위 | 필참자 전원 가능 **+** 전체 인원 중 일부 가능 |
| 3순위 | 필참자 전원이 가능하지는 않음 |

- 같은 등급 안에서는 **참석 가능 인원이 많은 순 → 날짜가 빠른 순 → 시작 시간이 빠른 순**
- 등급과 가능 인원이 같으면 공동 순위로 표시해요.
- 필참자가 없는 방은 등급 없이 참석 가능 인원 많은 순 → 날짜 → 시작 시간 순이에요.
- 아무도 가능하지 않은 시간과 설정한 종료 시각을 넘는 시간은 추천하지 않아요.

## 기술 구성

- HTML · CSS · Vanilla JavaScript (`index.html` 한 파일, 빌드 과정 없음)
- [Supabase](https://supabase.com) Database(방·참여자 공유 저장) + Realtime(실시간 반영), 브라우저에서 `supabase-js`를 CDN으로 불러와 사용
- 브라우저 `localStorage`: 프로필·테마·즐겨찾기·최근 방 등 개인 설정
- Google Fonts(Space Grotesk, Noto Sans KR)
- [Vercel](https://vercel.com) 정적 배포

## 실행 방법

- **배포 버전**: [https://cimo-pwc.vercel.app](https://cimo-pwc.vercel.app) 에 접속하면 돼요.
- **로컬에서 보기**: `index.html`을 브라우저로 열거나, 폴더에서 아무 정적 서버(예: `python -m http.server`)를 띄워 열어요.
  `index.html` 안의 `SUPABASE_CONFIG`에 Supabase 주소와 anon(publishable) 키가 있으면 공유 모드, 비어 있으면 이 기기에만 저장하는 미리보기 모드로 동작해요.
- **Supabase를 새로 만들 때**: SQL Editor에서 `supabase/schema.sql`을 실행한 뒤, Project URL과 anon 키를 `SUPABASE_CONFIG`에 넣어요. service_role 키는 넣으면 안 돼요.

## 프로젝트 구조

```
index.html            앱 전체(화면, 로직, Supabase 연동)
supabase/schema.sql   rooms · participants 테이블, RLS 정책, Realtime 설정
README.md
디자인_초안.png        초기 디자인 시안
프롬포트_초안.txt      초기 기획 프롬프트
```

## 알아둘 점

- 로그인이 없는 서비스라 방 코드나 링크를 아는 사람은 누구나 그 방을 보고 시간을 입력할 수 있어요. 방장 기능(확정·설정 변경)은 방장 비밀번호로 구분해요.
- 정원 제한은 저장 직전에 최신 참여자 목록을 다시 확인해서 막아요. 다만 두 사람이 완전히 같은 순간에 마지막 자리를 저장하는 극단적인 경우까지 DB 차원에서 막는 구조는 아니에요.
- 예시 방(202610)은 데모용이라 각 기기에만 저장돼요.
