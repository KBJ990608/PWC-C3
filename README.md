# 회시모 (CIMO)

단톡방 핑퐁은 그만, 링크 하나로 끝내는 5초 팀 일정 조율 웹앱

삼일회계법인 2026 Discover 신규입사자 연수 C-3조

## 지금 들어 있는 것

`index.html` 한 파일로 된 프로토타입이에요. 회의 만들기, 시간 칠하기, 1·2·3순위 추천, 황금칸과 컨페티, 참여 현황, 재촉·확정 문구 복사, 방 설정 수정, 즐겨찾기까지 들어 있어요.

## 열어보는 방법

`index.html`을 더블클릭하면 브라우저에서 바로 열려요. Vercel에 이 저장소를 연결하면 고정 주소로 배포돼요.

## 알아둘 점

이 버전은 데이터를 **브라우저에만 저장**하는 미리보기 모드로 동작해요. 그래서 내 휴대폰에서 칠한 시간이 팀원 화면에는 보이지 않아요. 팀원끼리 같은 방을 공유하려면 Claude Code로 공유 저장소(예: Vercel의 Upstash Redis)를 연결하는 작업이 다음 단계예요.

## 역할

- 기획·전략: 김세원, 양현준, 임채은
- 콘텐츠·데이터: 신민경, 윤수빈
- 빌드·개발: 김범준, 김영민, 최동욱
