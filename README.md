# 회시모 (CIMO)

단톡방 핑퐁은 그만, 링크 하나로 끝내는 5초 팀 일정 조율 웹앱

🔗 **배포 주소: [https://cimo-pwc.vercel.app](https://cimo-pwc.vercel.app)**

삼일회계법인 2026 Discover 신규입사자 연수 C-3조

## 구성

`index.html` 한 파일로 된 웹앱이에요. GitHub에 올리면 Vercel이 자동으로 배포해요.

- **공유 저장:** Supabase에 방과 참여자 데이터를 저장해서, 링크를 받은 팀원 모두가 같은 방을 봐요.
- **개인 데이터:** 내 정보(이름·부서·직급), 즐겨찾기, 최근 방, 테마는 각자 브라우저에 저장돼요.
- **예시 방:** "이용 방법 보기"로 여는 예시 방은 항상 각 기기에만 저장돼요.

## 주요 기능

**하단 탭:** 모임 / 캘린더 / 주간 / 내 정보

- **모임:** 진행 중인 조율, 지난 모임, 방 만들기, 6자리 코드로 참여, 이용 방법(예시 방)
- **캘린더:** 이 기기에서 들어간 모임을 달력으로 보기
- **주간:** 이번 주 확정된 모임을 요일별 시간표 블록으로 보기
- **내 참석 상태 표시:** 캘린더·주간·모임 목록에서 확정된 모임마다 나의 상태를 **참석 / 불참 / 미응답**으로 구분해요(주간: 색 블록 / 빗금 / 점선). "내가 참석하는 일정만 보기" 토글로 참석하는 모임만 볼 수 있어요. 시간 입력 화면의 "이미 확정된 내 회의" 표시도 참석하는 회의만 보여줘요.
- **내 정보:** 이름, 부서(선택: CM·TMT·IME·FS·직접 입력), 직급을 한 번 등록하면 방에 들어갈 때 자동 입력

**직급 규칙:** 직급은 앱 어디서든 **주니어 · 시니어 · 매니저 · 디렉터** 버튼 중에서만 골라요(내 정보, 방 만들기 필참자, 참가자 입력 모두 동일). 직접 타이핑은 없어서 오타로 필참자 인식이 빠지는 일이 없어요.

**방 만들기:** 모임 이름, 세부내용(선택), 후보 날짜, 시간대, 시간 단위(60·30·15분, 기본 60분), 소요 시간(1·2·3시간·직접 입력, 기본 1시간), 투표 마감(기본 일주일 뒤), 총 인원, 최소 참석 인원(기본 과반), 필참자(이름 선택 + 직급 버튼), 담당자 비밀번호. 만든 사람은 자동으로 담당자이자 필참자가 돼요.

**참가자 입력:** 이름 + 부서(선택, 내 정보와 같은 버튼) + 직급 버튼. 같은 이름·직급이 이미 있으면 "동일 정보가 기입되었습니다" 안내 후 기존 기록을 이어서 수정해요(부서 표기가 달라도 같은 사람으로 인식).

**방 안:** 시간 입력 / 추천 결과 / 참여 현황, 즐겨찾기, 방 설정 수정(최소 참석 인원 포함)

- **추천 결과:** TOP 3 순위 카드를 누르면 그 시간의 가능·불가능·투표 미참여 인원이 나와요. 추천보다 더 많이 모이는 시간은 **참고 카드(최대 3개)**로 함께 보여주고, 참고 카드를 골라 바로 확정할 수도 있어요.
- **참여 현황:** 진행 막대, 완료·미입력 인원, 초대·재촉 문구 복사. 완료한 사람 이름을 누르면 **그 사람이 고른 시간**이 날짜별로 보여요.
- **일정 확정 후:** 시간 입력 탭이 사라지고 확정 시간과 참여자 명단이 상단에 고정돼요. 담당자는 비밀번호로 **일정 변경**(순위·참고 카드 중 선택)이나 **일정 삭제**를 할 수 있어요.

**시간 입력 방법:** PC는 마우스로 누르거나 드래그해서 칠해요. 휴대폰은 칸을 톡 누르면 선택되고, "모바일 드래그 선택"을 켜면 드래그로 여러 칸을 칠할 수 있어요(끈 상태에선 표를 스크롤해도 칸이 바뀌지 않아요). 저장하면 추천 결과 탭으로 이동하고, 화면은 5초마다 자동으로 최신 상태로 갱신돼요.

## 추천 순위 규칙

추천 대상은 **필참자가 1명 이상 오고, 최소 참석 인원 이상 모이는 시간**이에요.

| 순위 | 조건 |
| --- | --- |
| 1순위 | 필참자 전원 + 총 인원 전원 |
| 2순위 | 필참자 전원 + 나머지 일부 |
| 3순위 | 필참자 일부 (필참자가 2명 이상인 방만) |

- 후보 구간은 "시작 시각 ~ 시작 시각 + 소요 시간"이고, 그 시간에 걸친 칸을 모두 칠한 사람만 참석 가능으로 계산 (예: 1시간 단위 표에 1시간 40분 회의 → 10:00~11:40)
- 같은 순위 안에서는 가능 인원이 많은 순, 같으면 빠른 날짜·시간 순
- TOP 3는 서로 시간이 겹치지 않는 구간으로 골라요
- 직급으로만 지정한 필참자는 그 직급 중 1명이 오면 충족
- 필참자는 이름 + 직급으로 확인해서, 부서가 붙어 있어도 같은 사람으로 인식
- 추천보다 더 많이 모이는 시간이 있으면 **참고 카드**로 따로 보여주고, 못 오는 필참자를 표시
- 해당하는 시간이 없으면 "추천 기준을 만족하는 시간이 없어요" 안내

## 수정하는 방법

1. 이 저장소에서 **최신** `index.html`을 내려받기
2. 새 Claude 채팅에 첨부하고 "기존 기능과 디자인은 유지하고 아래 수정사항만 반영해서 index.html 파일로 줘"라고 요청
3. 받은 파일 이름을 `index.html`로 맞춰서 [Add file] → [Upload files]로 덮어쓰기
4. 1~2분 뒤 [배포 주소](https://cimo-pwc.vercel.app)에서 확인

한 파일이라 두 사람이 동시에 고치면 나중에 올린 쪽이 앞의 수정을 덮어써요. 수정 전에 단톡방에 알리고 한 번에 한 사람만 작업해 주세요.

## 알아둘 점

- 로그인이 없어서 같은 이름·직급으로 들어오면 다른 사람의 입력을 고칠 수 있어요.
- **Supabase 권한:** `rooms`, `participants` 테이블에 RLS 정책이 **SELECT · INSERT · UPDATE** 모두 있어야 저장돼요(덮어쓰기 방식이라 UPDATE도 필요). 저장에 실패하면 앱이 "공유 저장에 실패했어요: (이유)"라고 알려줘요.
- **Vercel 연결:** 배포 주소에 수정이 안 보이면 Vercel 프로젝트 [Settings] → [Git]에서 이 저장소가 연결돼 있는지, [Deployments] 맨 위가 최신 커밋인지 확인해요.
- **claude.ai 미리보기:** 미리보기에서 복사되는 초대 링크는 코드에 고정된 아티팩트 주소를 써요. 실제 공유는 배포 주소를 써주세요.
- 이미 만들어진 방에 예전 방식(직급 직접 입력)으로 들어간 참가자 기록은 그대로 남아 있어요.

## 최근 변경 사항

**디자인**
- 주황 헤더(#D04A02), 선 아이콘, 카드·버튼 스타일로 전체 디자인 교체 (팀원 디자인 버전 기준)
- 이름·직급 표기("홍길동 FS · 시니어"), 용어("담당자"), 탭 이름 띄어쓰기, 알림 문구를 앱 전체에서 통일
- 하단 탭 항상 화면 맨 아래 고정, 작은 휴대폰에서 방 이름이 잘리지 않게 헤더 정리

**기능 (최근)**
- 참고 카드를 추천 순위가 있을 때도 표시, 참여 현황에서 사람별 투표 시간 보기
- 시간 단위 순서 60·30·15분(기본 60분), 소요 시간 기본 1시간
- 캘린더·주간에 참석·불참·미응답 구분 표시와 "내가 참석하는 일정만 보기" 토글 추가

**기능 (이전)**
- 내 정보: 부서 FS · 직접 입력 추가, 부서는 선택 사항으로 변경
- 참가자 입력 화면에도 부서(선택) 항목 추가해 내 정보와 입력 방식 통일
- 직급 입력을 모든 화면에서 버튼 선택으로 통일, 예시 방 직급도 목록에 맞게 변경
- 최소 참석 인원(기본 과반) 추가, 필참자가 1명 이상 와야 3순위, 참고 카드 추가

**오류 수정**
- 휴대폰에서 칸을 눌러도 선택되지 않던 문제 (터치 후 이벤트가 한 번 더 토글됨)
- 공유 저장 실패를 숨기고 이 기기에만 저장해 결과에 반영되지 않던 문제
- claude.ai 저장소에서 참여자 ID 형식 때문에 저장이 거부되던 문제
- 저장 후·탭 이동 시 화면이 최신 데이터로 갱신되지 않던 문제, 자동 갱신 시 표 스크롤이 튀던 문제
- 끝나는 시각이 칸 단위로 올림 표시·저장되던 문제, TOP 3끼리 시간이 겹치던 문제
- 부서 표기가 달라 같은 사람이 두 번 집계되던 문제, 방 설정 저장 시 미입장 필참자가 사라지던 문제
- 참여 현황 "N명 중 M명" 숫자 순서, 시간대 끝 시각 검사 누락, 이름 입력값이 지워지던 문제

## 역할

- 기획·전략: 김세원, 양현준, 임채은
- 콘텐츠·데이터: 신민경, 윤수빈
- 빌드·개발: 김범준, 김영민, 최동욱
